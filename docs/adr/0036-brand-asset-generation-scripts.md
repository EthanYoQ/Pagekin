# 品牌资产生成脚本的约定

2026-11-26，注释清理（#852）第 1 个 PR（scripts）。

## 背景

`scripts/brand/build-app-icons.mjs`、`scripts/brand/paper-ink-tokens.mjs` 与 `scripts/check-color-literals.mjs` 负责生成应用图标、生成文档里的纸墨令牌表、拦截颜色字面量。它们的实现里有一批渲染与校验细节的取舍，本 ADR 记录下来。脚本的用法与参数写在各脚本头部。

## 决定

### 一、应用图标

1. 在 Electron 的离屏窗口里按每个尺寸直接栅格化矢量图，小尺寸不靠缩放大图，边缘更干净。macOS 图标网格：1024 画布里圆角方块占 824，四周留白，与 Dock 里其他应用一样大。
2. 每个尺寸开一个新窗口：透明窗口复用时，上一次较大渲染的抗锯齿边缘会残留在左上角。`capturePage` 在窗口太小时会失败，所以窗口固定 1024，只截左上角 `size×size`。SVG 必须是块级，行内 SVG 落在文字基线上，16px 时会被行高往下推几像素，截图就丢掉底边；留白取整数像素，否则 16px 的 macOS 帧会糊成半像素边。
3. 隐藏窗口默认会节流 rAF 与绘制，可能永远等不到下一帧或截到空白，所以窗口保持可绘制。
4. 截图不对就不写进图标：校验尺寸、非全透明、四角透明、图形落在预期留白里（四边都对上才说明没被截掉或挪位）。满版渲染时包围盒发现不了背景不透明，图标是圆角方块、四角按设计透明，用它兜底；小尺寸圆角的抗锯齿会向外渗 1 像素，所以每边容差 1。
5. 主进程脚本里顶层 `await` 会卡住 `ready` 事件，所以用 `then` 串起来；每个尺寸用完就关窗口，空的 `window-all-closed` 处理函数避免「所有窗口已关闭」把应用提前退出。

### 二、纸墨令牌表

1. `tokens.css` 只接受固定写法，其余一律报错不放行。CSS 只把五个字符（空格、制表、换行、回车、换页）当空白，JS 的 `\s` 还包括不换行空格等，会让选择器校验放行改过的类名，所以正则显式列出这五个字符。
2. 令牌分类与用途取自设计系统文档与 `tokens.css` 的注释；每个令牌必须恰好落进一类，新增令牌没有归类时脚本报错，提醒补上用途。

### 三、颜色字面量

颜色只能来自一层令牌（design-system 第 6 条）：扫描组件与纸墨样式目录里的十六进制、rgb、hsl 字面量，除令牌文件与测试外一律不许有，没有允许清单。入口路径须解析后再比较（`import.meta.url` 是解析过符号链接与 junction 的真实路径），否则经链接运行时什么都不扫就退出 0。
